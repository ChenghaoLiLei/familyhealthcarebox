Health Box never sends your health records to cloud services on its own; by default everything is stored and processed on this phone.

What is stored

Family members’ names and notes; the originals you bring in (photos, PDFs, recordings, text); the text recognized from them and the suggested category and date; to-dos, appointments and reminder times; a local log of actions (when something was archived, imported, exported or deleted — no content). All of this stays on this iPhone. Each original is encrypted separately, and the key exists only in this iPhone’s keychain; it is not synced through iCloud Keychain.

What leaves the iPhone

Only what you do yourself: exporting an encrypted backup file (you choose where it goes and the password), or sending an original to someone with the system share sheet. There is no server, no account and no sign-in. The app never sends health data over the internet on its own.

What the app doesn’t do

No cloud AI, and no Apple Private Cloud Compute. No analytics, crash-reporting or advertising SDKs. Nothing is written to the system Photos library or Calendar. No automatic iCloud sync. The data folder is marked to be excluded from iCloud Backup, but that is a hint to the system, not a guarantee — we recommend turning off iCloud Backup for this app in the system settings.

Recognized text

Text in photos and PDFs is recognized on the iPhone with Apple’s on-device text recognition (Vision), only to suggest a category and find the document date. The result is stored locally with the original and can be deleted at any time.

Permissions used

Camera: to photograph and scan documents; photos are not saved to the system Photos library. Photos: to read only the pictures you pick. Files: to choose PDFs and backup files. Face ID / Touch ID: the app lock. Notifications: to-do reminders; the lock screen only shows “A family to-do is due”, never names, conditions or medicine names. Microphone and speech recognition: recordings and offline transcription (only when the system supports on-device recognition). Each permission can be turned off in the system settings at any time.

Delete

A single record, a single original, one family member, or all data on this iPhone can be deleted inside the app. Deleting cannot be undone. Uninstalling the app also deletes all data; backup files you exported yourself are not affected.

Backup files

Backup files are encrypted with the password you set (PBKDF2 + AES-GCM). The password is not stored anywhere. If it is lost, nobody can open the file — not even the developer.

Children

This app is not intended for children under 13 and does not collect information from children.
